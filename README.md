# 📸 Google Photo Gallery Clone
A responsive web application inspired by Google Photos, built with pure **HTML5** and **CSS3**. This project demonstrates front-end development skills with a clean, modern image gallery UI.

---

## 🚀 Key Features
* **Image Gallery**: Organizes photos into categories like **Plants**, **Animals**, and **Historical Places**.
* **Responsive Design**: A clean, modern UI with a navigation bar and hover effects for an intuitive user experience.
* **Dark Theme**: Custom CSS styling for an elegant and modern look.

---

## 🛠️ Tech Stack
* **Front-end**: HTML5, CSS3

---

## 📂 Project Structure
- `index.html`: The landing page with a modern hero section.
- `gallery.html`: The main hub for navigating different photo collections.
- `style.css`: Custom styling for dark theme and gallery layouts.

---

## 💻 How to Run
1. Clone the repository
2. Open `index.html` in any browser
3. No server setup required!
